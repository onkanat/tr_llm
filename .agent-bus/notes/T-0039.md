### 1. Özet ve Hedef
F2 (.bin yeniden derleme) ve F3 (taban model yetkinlik eğitimi) icraatına hazırlık olarak derleme giriş noktaları kanonik sözlüğe (`data/rebuild/vocab_base_32852.json`) ve `literal_entity_mode=True` moduna geçirildi; donmuş yollara kazaen yazma denemeleri engellendi ve istisna yutma kaldırıldı.
Bu görevde SADECE KOD güncellenmiş ve test koşulmuştur; hiçbir veri üretilmemiş, hiçbir `.bin`, `.pt` veya `vocab` dosyasına yazılmamıştır.

### 2. Uygulanan Değişiklikler

#### D1 & D2 & D3: `scripts/run_goal_pipeline.py`
1. `compile_jsonl_to_bin` fonksiyon imzası varsayılan olmadan zorunlu parametrelerle güncellendi:
   ```python
   def compile_jsonl_to_bin(
       jsonl_paths: list,
       output_bin: str,
       vocab_path: str,
       literal_entity_mode: bool,
       block_size: int = 64,
       oversample_factor: int = 1,
       allow_frozen_write: bool = False
   ) -> int:
   ```
2. **Donmuş Yol Koruması (D3):** `output_bin` yolu `.agent-bus/frozen.json` desenlerinden biriyle (`data/*.bin` dahil) eşleşiyorsa ve `allow_frozen_write=False` ise işlem derhal `RuntimeError` ile reddedilir.
3. **Sessiz Yutmanın Kaldırılması (D2):** `except Exception: continue` kaldırıldı. Bozuk kayıtlar `failed_records` sayacında biriktirilir, ilk 5 hata stderr'e loglanır ve `.meta.json` kütüğüne `failed_records` anahtarıyla kaydedilir.
4. **Çağrı Yerleri:** `run_goal_pipeline.py` içerisindeki 3 çağrı yeri (202, 219, 301) `vocab_path="data/rebuild/vocab_base_32852.json"` ve `literal_entity_mode=True` ile güncellendi.
5. `scripts/recompile_datasets.py` içerisindeki 3 çağrı yeri (32, 49, 62) kanonik parametrelerle ve F2 niyeti beyanı olarak `allow_frozen_write=True` ile güncellendi.

#### D4: `src/llm/prepare.py`
1. `prepare_dataset` fonksiyon imzası güncellendi:
   ```python
   def prepare_dataset(
       input_filepath: str,
       output_filepath: str,
       vocab_path: str = "data/rebuild/vocab_base_32852.json",
       literal_entity_mode: bool = True,
       save_vocab_to: str | None = None
   ):
   ```
2. Donmuş `data/vocab.json` dosyasına geri yazım engellendi. Sözlük kaydı yalnızca `save_vocab_to` açıkça verildiğinde ve hedef yol donmuş olmadığında yapılır; aksi takdirde `RuntimeError` fırlatılır.
