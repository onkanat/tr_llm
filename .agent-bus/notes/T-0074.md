# T-0074 — Ön-eğitim hedefi düzeltmesi (yürütücü notu)

Damga: 2026-09-18 (UTC) · Yürütücü: claude · Kiralamalar: `train.py`, `tests/`, `scratch/`,
`data/eval/`, `.agent-bus/notes`

## Neden açıldı

T-0073 sondasının 3 adımlık doğrulama koşumu `rc=0` ile bitti ama **`Kayıp (Loss): 0.0000`**
bastı. Rastgele başlatılmış bir model 1.024 jeton üzerinde 0 kayıp veremez.

## Tanı (ölçüldü, varsayılmadı)

`mask_prompt_targets` **kural 5**: *"`<OUTPUT>` içermeyen pencerelerde **tüm** hedefler -100"*.
A1 külliyatı düz metin; `<OUTPUT>` (id 1706) külliyatta **2 / 100.000.000**. Gerçek
`KristalDataset` pencerelerinde maske sonrası hayatta kalan hedef:

| blok | hayatta kalan | hayatta kalan pencere |
|---|---|---|
| 64 | 0 / 19.200 | 0/300 |
| 128 | 0 / 38.400 | 0/300 |
| 256 | 0 / 76.800 | 0/300 |

⇒ gradyan **tam sıfır**. Üstüne sessizlik: kayıp `ignore_index=1` (PAD) ile çağrılıyor, maskeden
`-100` çıkıyor → **CPU `IndexError`, MPS `0.0`** (ölçüldü, iki cihazda). Koşum MPS'te "başarılı"
görünüp 0,0000 bastı: hata yok, uyarı yok.

Kök neden temiz: `train.py` bir **SFT** eğiticisi. Depodaki ön-eğitim yolu düz-LM'dir ve prompt
maskesi kullanmaz (`train_step_a_ablation.py:61`, `train_step_b1_canonical.py:61` →
`model(x, y, sign_mask)`). **Eski Kristal zinciri bozuk değildi.**

## Yapılan

1. `train.py` → **`--pretrain`** modu: prompt maskesi **yok**, `<PAD>` maskesi **korunur**;
   bayraksız yol **aynen SFT** kalır.
2. Sessiz no-op'a karşı **`RuntimeError`**: maskeleme 0 hedef bırakırsa durur (cihazdan bağımsız).
3. Eğitim başlığında hedef modu görünür: `Hedef: ON-EGITIM (duz sonraki-jeton)`.
