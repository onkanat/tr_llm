## 2. Yapılan Değişiklikler

### A) `scripts/train_step_demo.py`
`mask_prompt_targets` saf fonksiyonu eklendi:
```python
def mask_prompt_targets(
    x: np.ndarray | torch.Tensor,
    targets: np.ndarray | torch.Tensor,
    output_start_id: int,
    eos_id: int
) -> np.ndarray:
```
- In-place mutasyon yapmaz (`np.array(targets, copy=True)` döner).
- `token_id == eos_id` görüldüğü anda `targets_np[b, i] = -100` atanarak sızıntı kapatılmıştır.
- Bir önceki token içerik tokeni iken `targets[k-1] == eos_id` olan hedef korunur; model `<EOS>` üretmeyi öğrenmeye devam eder.

### B) `train.py`
Eski satır içi döngü kaldırıldı ve tek satır saf fonksiyon çağrısına bağlandı:
```python
targets_np = mask_prompt_targets(x_cpu, y_cpu, output_start_id, eos_id)
```
