## 2. Yapılan Değişiklikler

### A. `train.py`
`train.py` içine `--loss-report` bayrağı aktifken periyodik olarak maskesiz hedef yüzdesini tek satır tanısal basan mantık eklendi:
```python
if loss_report:
    # G5 (T-0131): Maskesiz hedef oranı (hedef != -100) yüzde ölçeğinde periyodik beyan (tanısal)
    maskesiz_oran = float((targets != MASKE).float().mean().item()) * 100.0
    print(f"  [MASKE] Adım {step:4d} | Maskesiz Hedef Oranı: %{maskesiz_oran:.2f}", flush=True)
```
- Eşik yok, sessiz durdurma veya varsayım yok; saf tanısal beyan.

### B. `tests/test_prompt_masking.py`
Mevcut 6 teste ilave olarak 4 yeni kapsamlı test eklendi (toplam 10/10 test):
1. `test_multi_record_window_masking`: Aynı pencerede ardışık birden fazla soru-cevap (çoklu kayıt) bulunduğunda her iki prompt ve EOS geçişinin doğru maskelendiğini, cevapların korunduğunu denetler.
2. `test_clipped_prompt_without_output`: Kırpılmış pencerede yalnızca prompt kuyruğu kaldığında ve `<OUTPUT>` bulunmadığında tüm hedeflerin -100 yapıldığını denetler.
3. `test_clipped_output_without_eos`: Pencere `<OUTPUT>` ile başlayıp `<EOS>` gelmeden kesildiğinde tüm çıktı hedeflerinin korunduğunu denetler.
4. `test_mutant_leakage_detection`:
   - Sentetik prompt sızıntısı mutantı (`_mutant_leak_prompt_targets`) -> **KIRMIZI** (`AssertionError: Prompt hedefi maskelenmemiş`).
   - EOS sızıntısı mutantı (`_mutant_leak_eos_targets`) -> **KIRMIZI** (`AssertionError: EOS konumundaki hedef maskelenmemiş`).
   - Temiz fonksiyon -> **YEŞİL**.

### B. Kayıp Seyreltme İlişkisi Notu
- PyTorch `CrossEntropyLoss(ignore_index=-100, reduction='mean')` hesaplamasında, payda maskeli token'ları hesaba katmaz; ortalama yalnızca maskesiz (aktif) jetonlar üzerinden alınır.
- Dolayısıyla kayıp seyreltmesi doğrudan kayıp değerini sıfıra yaklaştırmaz, ancak gradyanların temsil ettiği token havuzu maskesiz orana göre değişir: `Efektif Kayıp Ağırlığı ∝ Maskesiz Jeton Sayısı`.
- Maskesiz hedef oranı beyanı, batch içinde öğrenilen sinyalin yoğunluğunu izlemek için kritik bir gözlemlenebilirlik sağlar.
